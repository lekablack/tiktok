Política de Privacidade

Última atualização: 19 de agosto de 2026

1. Sobre o TikTok Agent

O TikTok Agent é uma ferramenta de gerenciamento e publicação de conteúdo desenvolvida para auxiliar na organização e publicação de vídeos em uma conta TikTok autorizada pelo usuário.

O serviço utiliza recursos disponibilizados pela plataforma TikTok por meio das APIs oficiais do TikTok for Developers.

2. Informações acessadas

Quando o usuário autoriza o aplicativo, o TikTok Agent poderá acessar informações necessárias para identificar a conta autorizada e realizar as funções solicitadas pelo usuário.

Dependendo das permissões autorizadas, essas informações podem incluir identificadores básicos da conta e autorização para publicar conteúdo em nome do usuário.

3. Conteúdo enviado pelo usuário

Os vídeos utilizados pelo TikTok Agent são fornecidos pelo próprio usuário e armazenados localmente no ambiente utilizado pelo serviço.

O TikTok Agent utiliza esses arquivos exclusivamente para executar as ações solicitadas pelo usuário, incluindo o envio de conteúdo para o TikTok por meio da API oficial.

4. Uso das informações

As informações acessadas são utilizadas exclusivamente para:

  • identificar a conta TikTok autorizada;
  • realizar a autenticação e autorização do usuário;
  • enviar conteúdo para publicação quando solicitado;
  • executar as funcionalidades disponibilizadas pelo aplicativo.

5. Compartilhamento de informações

O TikTok Agent não vende, aluga ou comercializa informações pessoais dos usuários.

As informações e conteúdos necessários para executar uma publicação são transmitidos ao TikTok por meio das APIs oficiais e de acordo com as permissões concedidas pelo usuário.

6. Armazenamento e segurança

O aplicativo busca manter as informações e credenciais de acesso protegidas contra acesso não autorizado.

Os arquivos de vídeo utilizados pelo aplicativo são mantidos no ambiente local utilizado pelo usuário, salvo quando forem enviados ao TikTok para execução de uma ação solicitada.

7. Controle do usuário

O usuário mantém o controle sobre sua conta TikTok e pode revogar as autorizações concedidas ao aplicativo por meio dos mecanismos disponibilizados pelo TikTok.

8. Serviços de terceiros

O aplicativo utiliza serviços e APIs fornecidos pelo TikTok para realizar as funcionalidades de autenticação e publicação de conteúdo.

O uso desses serviços também está sujeito às políticas e termos aplicáveis do respectivo provedor.

9. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada quando necessário para refletir alterações no funcionamento do aplicativo, nos serviços utilizados ou nas obrigações legais aplicáveis.

10. Contato

Para dúvidas, solicitações ou questões relacionadas a esta Política de Privacidade, entre em contato pelo endereço de e-mail associado ao projeto TikTok Agent.
